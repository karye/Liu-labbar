# Liu-labbar

* Labbar från kursen **Att undervisa artificiell intelligens på gymnasial nivå – tekniska perspektiv (961G56 2026VT RU)**
* https://liuonline.sharepoint.com/sites/Lisam_961G56_2026VT_RU

## Kursöversikt
Detta repository innehåller labbmaterial och notebooks för en kurs i undervisning av AI på gymnasienivå. Materialet är organiserat modulvis där varje modul fokuserar på en annan ansats (systematisk problemlösning eller datadrivet lärande).

## Hur man använder repot
- Öppna notebooks direkt i Google Colab via de delade länkarna eller genom att öppna filerna i mappen och ladda upp dem till Colab.
- Följ lektionens steg, kör cellerna i ordning och använd `Lab_Facit`-notebooks för att jämföra lösningar.
